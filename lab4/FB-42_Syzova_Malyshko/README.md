# Лабораторна робота №4 з Криптографії

**Вивчення криптосистеми RSA та алгоритму електронного підпису; ознайомлення з методами генерації параметрів для асиметричних криптосистем.**

**Виконали студентки групи ФБ-42:**
* Сизова Марія
* Малишко Дарія

### Що реалізовано (lab4.py):
1. Швидке піднесення до степеня за модулем (Схема Горнера) та алгоритми Евкліда.
2. Ймовірнісний тест перевірки на простоту Міллера-Рабіна та тест пробних ділень.
3. Генерація «безпечних» простих чисел (числа Софі Жермен).
4. Побудова криптосистеми RSA (генерація ключів, шифрування, розшифрування).
5. Створення та перевірка електронного цифрового підпису.
6. Протокол безпечного розсилання ключів між абонентами А та В.
